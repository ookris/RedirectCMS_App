Audit Log

Audit Log to dziennik wszystkich zmian dokonanych w systemie. Rejestruje kto, kiedy i co zmienił.

Co jest rejestrowane?

System automatycznie loguje:

Typy akcji

Akcja Opis
CREATE Utworzenie nowego elementu
UPDATE Modyfikacja istniejącego elementu
DELETE Usunięcie elementu (do kosza lub trwale)
RESTORE Przywrócenie z kosza
LOGIN Zalogowanie do panelu
LOGOUT Wylogowanie
SETTINGS Zmiana ustawień

Typy encji

Encja Opis
Link Skrócone linki
Campaign Kampanie
Page Strony CMS
Category Kategorie
Tag Tagi
AffiliateProgram Programy afiliacyjne
User Konta użytkowników
Settings Ustawienia systemu
CronJob Zadania cron

Przeglądanie logów

Lista logów wyświetla:

  • Data i godzina - kiedy wykonano akcję
  • Akcja - typ operacji (CREATE, UPDATE, itp.)
  • Encja - na czym wykonano akcję
  • ID encji - identyfikator elementu
  • Użytkownik - kto wykonał akcję (nazwa lub "System")
  • IP - adres IP użytkownika

Filtrowanie

Możesz filtrować logi według:

  • Typ akcji - CREATE, UPDATE, DELETE, itp.
  • Typ encji - Link, Category, itp.
  • Data od/do - zakres dat
  • Szukaj - po IP lub nazwie użytkownika

Szczegóły zmiany

Kliknięcie w wiersz logu rozwija szczegóły:

  • Stare wartości - dane przed zmianą
  • Nowe wartości - dane po zmianie
  • User Agent - przeglądarka użytkownika

Automatyczne czyszczenie

Zadanie cron clean_audit_logs automatycznie usuwa logi starsze niż 90 dni. Możesz to zmienić lub wyłączyć na stronie Zadania Cron.

Zastosowania

  • Bezpieczeństwo - wykrywanie nieautoryzowanych zmian
  • Debugowanie - śledzenie co spowodowało problem
  • Audyt - zgodność z wymogami prawnymi
  • Odzyskiwanie - podgląd starych wartości przed zmianą
