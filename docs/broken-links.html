Sprawdzanie linków

System automatycznie sprawdza czy linki docelowe są dostępne. Pomaga wykrywać martwe linki zanim zauważą to użytkownicy.

Podsumowanie

Na górze strony wyświetlane są statystyki:

Metryka Opis
Wszystkie linki Całkowita liczba linków w systemie
Zdrowe Linki zwracające status 200 OK
Uszkodzone Linki zwracające błędy (4xx, 5xx)
Ignorowane Linki oznaczone do pominięcia sprawdzania
Naprawione Linki oznaczone jako naprawione
Niesprawdzone Linki bez historii sprawdzania

Lista uszkodzonych linków

Tabela wyświetla linki z problemami:

  • Slug / Tytuł - identyfikator linku
  • URL docelowy - adres który jest nieosiągalny
  • Status HTTP - kod odpowiedzi (np. 404, 500)
  • Komunikat - szczegóły błędu
  • Ostatnie sprawdzenie - kiedy sprawdzono

Statusy HTTP

Kod Znaczenie Działanie
200 OK - strona działa Brak akcji wymaganych
301/302 Przekierowanie Może wymagać aktualizacji URL
403 Dostęp zabroniony Sprawdź czy strona wymaga logowania
404 Nie znaleziono Strona nie istnieje - zaktualizuj lub usuń link
500 Błąd serwera Problem po stronie docelowej - może być tymczasowy
Timeout Przekroczenie czasu Serwer docelowy nie odpowiada

Akcje

Sprawdź ponownie

Wymusza natychmiastowe sprawdzenie linku. Przydatne jeśli naprawiłeś problem po stronie docelowej.

Ignoruj

Oznacza link do pominięcia przy sprawdzaniu. Używaj dla linków które:

  • Wymagają logowania (zwracają 403)
  • Blokują boty (zwracają 403)
  • Są specjalnie skonfigurowane

Oznacz jako naprawiony

Oznacza że problem został rozwiązany. Link będzie ponownie sprawdzony przy następnym cyklu.

Edytuj link

Otwiera formularz edycji linku, gdzie możesz zaktualizować URL docelowy.

Automatyczne sprawdzanie

Zadanie cron check_broken_links sprawdza linki co 24 godziny. Upewnij się, że cron jest skonfigurowany.

Historia sprawdzeń

System przechowuje historię ostatnich 10 sprawdzeń dla każdego linku. Zadanie cron clean_link_health_history czyści starszą historię.

Dobre praktyki

  • Regularnie przeglądaj listę uszkodzonych linków
  • Naprawiaj linki 404 najszybciej jak to możliwe
  • Unikaj linkowania do niestabilnych stron
  • Używaj "Ignoruj" świadomie - tylko dla uzasadnionych przypadków
