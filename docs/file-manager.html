Menedżer plików

Menedżer plików pozwala przeglądać i zarządzać plikami w katalogu /uploads.

Statystyki

Na górze strony wyświetlane są:

  • Całkowity rozmiar - suma wszystkich plików
  • Liczba plików - ilość plików w katalogu
  • Katalog główny - ścieżka do /uploads

Nawigacja

Breadcrumbs

Na górze listy wyświetlane są okruszki (breadcrumbs) pokazujące aktualną ścieżkę. Kliknij w dowolny element, aby przejść do tego katalogu.

Wchodzenie do folderów

Kliknij nazwę folderu, aby do niego wejść.

Powrót wyżej

Kliknij ".." lub odpowiedni element breadcrumbs, aby wrócić do katalogu nadrzędnego.

Lista plików

Tabela wyświetla:

  • Ikona - typ pliku (folder, obrazek, dokument)
  • Nazwa - nazwa pliku lub folderu
  • Rozmiar - wielkość pliku
  • Data modyfikacji - ostatnia zmiana
  • Akcje - dostępne operacje

Akcje na plikach

Podgląd

Dla obrazków dostępny jest podgląd miniaturki.

Pobierz

Kliknij ikonę pobierania, aby ściągnąć plik na komputer.

Usuń

Kliknij ikonę kosza, aby usunąć plik. Operacja jest nieodwracalna.

Uwaga: Usuwanie plików używanych przez linki lub ustawienia może spowodować błędy wyświetlania (brakujące obrazki).

Struktura katalogów

Standardowa struktura /uploads:

/uploads/
├── images/        # Obrazki linków (OG images)
├── branding/      # Logo i favicon
└── categories/    # Ikony kategorii

Obsługiwane formaty

Obrazki

  • JPG / JPEG
  • PNG
  • GIF
  • WebP

Limity

  • Maksymalny rozmiar pliku: zależny od konfiguracji PHP (upload_max_filesize)
  • Limit miejsca: konfigurowalny w Ustawieniach

Automatyczne czyszczenie

Zadanie cron clean_orphan_uploads automatycznie usuwa pliki które:

  • Nie są przypisane do żadnego linku
  • Nie są używane w ustawieniach (logo, favicon)
  • Nie są ikonami kategorii
Wskazówka: Jeśli plik został usunięty omyłkowo przez automatyczne czyszczenie, prześlij go ponownie.

Bezpieczeństwo

  • Dozwolone są tylko bezpieczne typy plików (obrazki)
  • Nazwy plików są sanityzowane przy uploadzie
  • Pliki wykonywalne są blokowane
  • Dostęp do menedżera wymaga zalogowania
