Pierwsze kroki

Ten przewodnik pomoże Ci szybko rozpocząć pracę z RedirectCMS - od pierwszego logowania do utworzenia pierwszego skróconego linku.

Wymagania systemowe

RedirectCMS wymaga:

  • PHP 8.0 lub nowszy
  • MySQL 5.7 / MariaDB 10.3 lub nowszy
  • Serwer WWW (Apache z mod_rewrite lub Nginx)
  • Rozszerzenia PHP: PDO, pdo_mysql, json, mbstring, curl

Logowanie do panelu

Panel administracyjny dostępny jest pod adresem:

https://twoja-domena.pl/admin/

Wprowadź dane logowania skonfigurowane podczas instalacji:

  • Login - nazwa użytkownika administratora
  • Hasło - hasło do konta
Wskazówka: Jeśli zapomniałeś hasła i nie możesz zalogować się do panelu, możesz je zresetować edytując rekordy admin_username i admin_password_hash w tabeli settings. Nową wartość hash wygenerujesz przez password_hash('nowehaslo', PASSWORD_DEFAULT).

Przegląd interfejsu

Po zalogowaniu zobaczysz panel główny (Dashboard) z:

  • Pasek nawigacyjny - szybki dostęp do wszystkich sekcji
  • Widgety statystyk - podsumowanie kliknięć i linków
  • Lista ostatnich linków - Twoje najnowsze linki
  • Top linki - najpopularniejsze linki
Powiadomienia: W prawym górnym rogu paska nawigacyjnego znajduje się dzwonek z badge'em - kliknij, aby zobaczyć powiadomienia systemowe. Obok dzwonka dostępna jest ikona lupy (wyszukiwarka globalna).

Tworzenie pierwszego linku

Aby utworzyć skrócony link:

  1. Kliknij przycisk "Nowy link" w pasku nawigacyjnym
  2. Wypełnij formularz:
    • Slug - krótki identyfikator linku (np. "promocja2024"). Zostaw puste, aby wygenerować losowy.
    • URL docelowy - pełny adres URL, do którego ma prowadzić link
    • Tytuł (opcjonalnie) - tytuł wyświetlany na stronie przekierowania
  3. Kliknij "Zapisz"
Gotowe! Twój skrócony link jest dostępny pod adresem: https://twoja-domena.pl/slug

Opcje zaawansowane

Przy tworzeniu linku możesz również ustawić:

  • Kategoria - przypisanie do kategorii
  • Program afiliacyjny - oznaczenie programem partnerskim
  • Tagi - dodanie tagów do linku
  • Opóźnienie - czas przed przekierowaniem (w sekundach)
  • Data publikacji - zaplanowanie aktywacji linku
  • Data wygaśnięcia - automatyczna dezaktywacja
  • Opis - meta description dla SEO
  • Obrazek OG - obrazek dla mediów społecznościowych
  • UTM Builder - kreator parametrów UTM dostępny w formularzu edycji linku

Następne kroki

Po utworzeniu pierwszego linku możesz:

  • Utworzyć kategorie do organizacji linków
  • Sprawdzić statystyki kliknięć
  • Skonfigurować ustawienia systemu
  • Zaimportować linki z pliku CSV
  • Włączyć 2FA dla większego bezpieczeństwa
