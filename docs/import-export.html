Import / Export

RedirectCMS pozwala na masowy import linków z pliku CSV oraz eksport danych do dalszej analizy.

Import linków z CSV

Dostęp do importu

Na stronie "Linki" kliknij przycisk "Importuj CSV".

Format pliku CSV

Plik musi być w formacie CSV z separatorem średnikiem (;).

Wymagane kolumny

Kolumna Opis
slug Unikalny identyfikator linku
target_url Pełny URL docelowy (z http:// lub https://)

Opcjonalne kolumny

Kolumna Opis
id ID linku (dla aktualizacji istniejących)
title Tytuł linku
description Opis / meta description
category Nazwa kategorii
affiliate_program Nazwa programu afiliacyjnego
delay Opóźnienie przekierowania (sekundy)
publish_at Data publikacji (format: YYYY-MM-DD HH:MM:SS)
expires_at Data wygaśnięcia (format: YYYY-MM-DD HH:MM:SS)

Przykładowy plik CSV

slug;target_url;title;category;affiliate_program
promo1;https://example.com/product1;Promocja produktu 1;Elektronika;Amazon
promo2;https://example.com/product2;Promocja produktu 2;Moda;Allegro
promo3;https://example.com/product3;Promocja produktu 3;;

Podgląd CSV i mapowanie kolumn

Po wybraniu pliku CSV system wyświetla podgląd danych przed właściwym importem. Pozwala to:

  • Sprawdzić poprawność wczytanych danych
  • Zmapować kolumny z pliku na pola systemu (jeśli nazwy kolumn różnią się od standardowych)
  • Wykryć błędy w strukturze pliku przed importem

Dopiero po zatwierdzeniu podglądu i mapowania możesz uruchomić właściwy import.

Opcje importu

Opcja Opis
Pomiń pierwszy wiersz Zaznacz, jeśli pierwszy wiersz zawiera nagłówki kolumn
Aktualizuj istniejące Jeśli slug już istnieje, zaktualizuj dane zamiast tworzyć nowy

Proces importu

  1. Wybierz plik CSV
  2. Sprawdź podgląd danych i skonfiguruj mapowanie kolumn
  3. Zaznacz odpowiednie opcje
  4. Kliknij "Importuj"
  5. System przetworzy plik i wyświetli podsumowanie:
    • Liczba zaimportowanych linków
    • Liczba zaktualizowanych linków
    • Liczba błędów (z opisami)
Wskazówka: Przed importem dużej ilości linków, przetestuj na małym pliku (5-10 wierszy).

Pobierz szablon

Kliknij "Pobierz szablon CSV", aby pobrać przykładowy plik z prawidłową strukturą kolumn.

Eksport linków do CSV

Eksport wszystkich linków

Na stronie "Linki" kliknij przycisk "Eksportuj CSV", aby pobrać wszystkie linki.

Eksport z filtrami

Jeśli zastosowałeś filtry (kategoria, program, wyszukiwanie), eksport pobierze tylko przefiltrowane linki.

Eksport zaznaczonych

Możesz zaznaczyć wybrane linki na liście i użyć akcji masowej "Eksportuj zaznaczone", aby pobrać tylko wybrane rekordy.

Zawartość eksportu

Eksportowany plik zawiera wszystkie kolumny:

  • id, slug, target_url
  • title, description
  • category, affiliate_program
  • tags (tagi oddzielone przecinkami)
  • delay, clicks
  • publish_at, expires_at
  • created_at, updated_at

Eksport statystyk

Na stronie Statystyki pojedynczego linku możesz eksportować dane w formatach:

  • CSV - dane dzienne, źródła, urządzenia, przeglądarki, godziny
  • JSON - wszystkie dane w formacie JSON

Dobre praktyki

  • Przed importem wykonaj kopię zapasową bazy danych
  • Sprawdź poprawność URL-i w pliku CSV przed importem
  • Używaj unikalnych slugów - duplikaty spowodują błędy lub nadpisanie
  • Dla dużych importów (>1000 linków) podziel plik na mniejsze części
  • Zawsze sprawdzaj podgląd przed zatwierdzeniem importu
